## ✨ 功能特性

| 模块 | 说明 |
|---|---|
| **AI 自动答题** | 接入云端 DeepSeek（默认 **V4 Flash**），支持单选、多选、判断、填空、简答、名词解释 |
| **智能回填** | 答案按**字母索引 + 文本相似度**双通道定位，覆盖各类选项写法（`B` / `A,C` / 全角 `Ｂ`） |
| **自动刷课** | 视频倍速 / 秒过、文档与图书自动完成、章节作业自动提交、自动进入下一章节 |
| **字体解密** | 自动还原学习通加密字体，复制 / 搜题不再乱码 |
| **移动端适配** | 针对手机 / 窄屏浏览器优化的面板布局 |
| **液态玻璃 UI** | 面板、标签、用量栏均为玻璃质感；标签切到激活态会呼吸发光 |
| **鲸娘伴生** | 空闲态鲸娘浮动 + 变色光晕，语录池随好感度成长 |
| **好感度系统** | 按累计花费分 5 档解锁语录（¥0 / ¥1 / ¥2 / ¥5 / ¥10），满级 50 条 |
| **运行状态灯** | 最小化后图标前有浮动光点：绿=运行中 / 黄=答题中 / 红=已终止 |
| **智能路由** | 默认停在鲸娘页；状态页有新动静就自动切过去，安静 3 秒回鲸娘页 |

## 📦 安装

推荐使用 **脚本猫（ScriptCat）** 承载：

1. 在 Edge / Chrome 应用商店安装 [脚本猫](https://scriptcat.org/) 扩展。
2. 下载本仓库的 [`海底小纵队·探矿鲸娘.user.js`](海底小纵队·探矿鲸娘.user.js)（或直接拖入浏览器），脚本猫会弹出安装页，点击「安装」。
3. 安装后访问学习通课程页面，即可看到助手面板。

> 也可使用篡改猴（Tampermonkey）。
> **请勿同时启用多个脚本管理器并重复安装本脚本，以免双注入。**
> 若同时装过多个版本，脚本自带互斥清场逻辑：非自身实例的面板会被自动隐藏（不删除，刷新即恢复）。

## ⚙️ AI 配置

打开助手面板 →「配置」页 → **AI** 卡片：

1. 前往 <https://platform.deepseek.com/> 注册并创建一个 `sk-` 开头的 API Key。
2. 在 AI 卡片中粘贴 **API Key**，选择模型（**DeepSeek V4 Pro / Flash**）。
3. 可选：填一个 **小名**（最多 12 字）——填了之后，鲸娘语录里的自称会换成这个名字。
4. 刷新课程页面，进入章节测验即可自动逐题作答并填入。

配置仅保存在你本地的脚本管理器存储中，不会上传到任何第三方（API 请求除外）。

## 💡 使用说明

底栏共 5 个页签：

| 页签 | 用途 |
|---|---|
| **状态** | 运行日志（鲸娘口吻），最小化时只保留标题栏 |
| **鲸娘** | 默认首页。空闲态显示鲸娘与语录；作答态显示进度 |
| **配置** | AI 卡片（Key / 模型 / 小名 / 好感度）与刷课参数 |
| **教程** | 使用说明与常见问题 |
| **协议** | 使用声明（共 6 项） |

- 空闲态鲸娘下方会展示当前 API 账号**余额**（`GET api.deepseek.com/user/balance`，10 分钟自动刷新，可点击手动刷新）。
- 底部用量栏：**本次**（本次启用脚本后的请求数）/ **运行**（本次运行时长）/ **总花费**（累计花费）/ **好感度**（当前档位）。点「本次」格可随时把本次统计基线归零（刷完一门课的花销不到1元）。
- 建议先在一门课程上小范围验证，再开启「自动提交 / 自动下一章节」批量运行。

### 好感度档位

| 等级 | 累计花费门槛 | 等级名 | 称号 |
|---|---|---|---|
| Lv.1 | ¥0 | 初见 | 陌生的小鲸娘 |
| Lv.2 | ¥1 | 搭话 | 点头之交 |
| Lv.3 | ¥2 | 熟络 | 常来串门 |
| Lv.4 | ¥5 | 亲密 | 形影不离 |
| Lv.5 | ¥10 | 相伴 | 鲸生有你 |

每档追加解锁 10 条语录，满级共 50 条。当前档位与解锁进度在**配置页 AI 卡片的「小名」下方**，点旁边的 ⓘ 可展开机制说明。

### 控制台探针

面板挂载后可在页面控制台自查版本与运行状态：

| 探针 | 作用 |
|---|---|
| `__HX_BUILD__` | 当前脚本版本字符串 |
| `__HX_DIAG__()` | 挂载诊断（页签、面板宿主、答题/配置页快照） |
| `__HX_STATUS__()` | 状态灯判定结果（`run` / `busy` / `stop`） |
| `__HX_FAV__()` | 好感度（累计花费、档位、已解锁条数、卡片是否挂上） |
| `__HX_NAME__()` / `__HX_LINE__()` | 当前小名 / 当前这句话录 |
| `__HX_TAB__()` | 智能路由状态（是否在答题、上一拍是否在答题） |
| `__HX_BALANCE__()` | 账户余额缓存快照 |
| `__HX_SESSION_RESET__()` | 重置「本次」统计基线 |
